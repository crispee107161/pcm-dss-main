A Decision Support System (DSS) for Facebook Content Performance and Advertising Efficiency Analysis at PC Merchandise

 Important to Remember

NO SALES OR PURCHASES DATA: Completely drop all purchases, sales, and transaction metrics. We are strictly focusing on ad efficiency, expense reduction, engagement, and customer inquiries.
NLP for Keywords: We don't upload keywords manually via CSV. Instead, the system uses NLP (Natural Language Processing) to automatically read the uploaded Facebook CSV file and pull out relevant keywords from post text and customer comments.
