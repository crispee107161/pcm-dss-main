## 3. What-If Simulation — Cost-Cutting Scenario Recommender

**Status:** DONE (2026-08-04) — revisit only if something comes up later.

**Implemented:** `lib/stats/ad-set-metrics.ts` (shared ad-set aggregation/efficiency helper, extracted out of `budget-allocator.ts`), `lib/stats/cost-cutting.ts` (`computeCostCuttingScenario`), `actions/cost-cutting.ts` (`runCostCuttingScenario`), `components/analytics/CostCuttingScenario.tsx`, wired into `components/analytics/pages/SimulationView.tsx` as a third card under Budget Allocator. Tests in `lib/stats/cost-cutting.test.ts` (5 new, later +2 for the intercept/zero-inquiry fixes). Verified: tsc clean, tests passing, production build succeeds.

**Goal:** Given current ad-set spend, recommend which ad sets to cut/reduce to hit a target budget reduction (e.g. −20%), showing concrete peso savings against the resulting inquiry loss. Complements the existing single-point simulator (`components/analytics/WhatIfSimulator.tsx`) and the "allocate a new budget" flow (`components/analytics/BudgetAllocator.tsx`, `lib/stats/budget-allocator.ts`).

**Plan:**
1. **Logic** — `lib/stats/cost-cutting.ts`, exporting `computeCostCuttingScenario(reductionPct: number)`:
   - Extract the existing ad-set aggregation/efficiency grouping out of `lib/stats/budget-allocator.ts` into a shared helper so it isn't duplicated.
   - Sort ad sets by efficiency ascending (least efficient = cut candidates first).
   - Greedily mark lowest-efficiency ad sets for cuts until cumulative spend removed ≥ `reductionPct * totalSpend`.
   - Project inquiries for the remaining (kept) ad sets using the same regression-model projection `budget-allocator.ts` already uses.
   - Return `{ totalSpend, targetReduction, actualReduction, cutAdSets, keptAdSets, baseline_projected_inquiries, after_cut_projected_inquiries, inquiry_loss_pct }`.
2. **Server action** — `runCostCuttingScenario` (new file `actions/cost-cutting.ts` or added to `actions/allocate.ts`), mirroring the `useActionState` pattern already used by `runBudgetAllocation`.
3. **UI** — `components/analytics/CostCuttingScenario.tsx`: input a target reduction %, output a table of ad sets recommended for cutting (with savings) plus a before/after inquiry-projection summary banner, styled like `BudgetAllocator.tsx`.
4. **Wire in** — add as a third card in `components/analytics/pages/SimulationView.tsx`, under the existing Budget Allocator card.
5. **Tests** — `lib/stats/cost-cutting.test.ts` covering the greedy-cut selection logic, following the pattern in `lib/stats/budget-allocator.test.ts`.
